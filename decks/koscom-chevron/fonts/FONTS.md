# KoPub돋움체 (KoPub Dotum)

`koscom-chevron` is the one template in this pack that is **not** locked to Pretendard. Koscom's official sample decks are set in **KoPub돋움체 Bold / Medium**, and the template keeps that lock so an exported deck reads as the house material.

| File | Family name (KR / EN) | Used for |
|---|---|---|
| `KoPubDotum-Bold.ttf` | KoPub돋움체 Bold / KoPubDotum Bold | every headline, card title, agenda number, KPI, brand mark |
| `KoPubDotum-Medium.ttf` | KoPub돋움체 Medium / KoPubDotum Medium | body, lead, kicker, captions, axis labels |
| `KoPubDotum-Light.ttf` | KoPub돋움체 Light / KoPubDotum Light | not used by the roster — shipped so the family is complete |

Install all three on any machine that opens the exported PPTX (PPTX does not embed fonts). If the family is missing, the `font-family` stacks fall back to Pretendard, then Malgun Gothic.
